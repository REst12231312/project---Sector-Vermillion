# Sector: Vermillion

Учебный игровой сайт по вселенной Warhammer 40,000. Игрок входит или создаёт аккаунт, изучает досье, находит ключевые термины и открывает связанные полевые записи и новые зоны.

## Запуск

Нужен Node.js 18 или новее.

1. Установить зависимости интерфейса: `npm install`.
2. Установить зависимости API: `npm --prefix ../backend install`.
3. Запустить API в отдельном окне терминала: `npm run server` (порт 4000).
4. Запустить интерфейс во втором окне: `npm start` (порт 3000).

Для регистрации, входа и игры нужны оба процесса: React-интерфейс и Express API.

## Игровая цепочка

При изучении досье Империума находится термин «НЕОФИТ», у Орков — «ВААГХ!», у Хаоса — «ВАРП». Каждый термин открывает связанную запись. Если прочитать все три, архив объединит свидетельства и откроет зону VER-IX с заметкой о битве у Пепельного маяка и загадкой о найденной стазисной камере. Это авторский сюжет проекта, не официальный канон. За чтение записей выдаётся XP. Прогресс привязан к аккаунту и хранится в `../backend/data/progress.json`.

## API

- `GET /api/health` — состояние сервиса.
- `POST /api/auth/register` — регистрация аккаунта.
- `POST /api/auth/login` — вход и получение токена.
- `GET /api/auth/me` — текущий аккаунт.
- `GET /api/progress` — прогресс текущего аккаунта.
- `POST /api/study/:factionId` — запись изученного досье и награда.
- `POST /api/quiz` — серверная проверка ответа и выдача опыта.
- `GET /api/knowledge` — обнаруженные термины и состояние лор-записей.
- `POST /api/knowledge/:entryId/read` — чтение открытой записи и награда XP.

Пароли обрабатываются встроенным `scrypt`; API выдаёт подписанный токен со сроком действия 7 дней. Учётные записи и прогресс сохраняются в JSON-файлах папки `../backend/data/`, ключ подписи создаётся при первом запуске и исключён из Git. Для крупного публичного запуска JSON-хранилище стоит заменить на базу данных и добавить ограничение частоты попыток входа.
